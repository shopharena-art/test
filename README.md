# CI Builder

اپ اندروید برای کامپایل پروژه‌ها (APK و EXE) روی GitHub Actions. کل این پوشه همان ریپوی گیت‌هاب است.

## راه‌اندازی (بدون Android Studio)

1. یک ریپوی **عمومی** جدید در گیت‌هاب بسازید.
2. زیپ را باز کنید و **محتویات** آن (پوشه‌های `.github` و `android` و فایل‌های دیگر) را با Add file → Upload files در ریپو آپلود و Commit کنید. (پوشه‌ها را بکشید و رها کنید.)
3. تب **Actions** را باز کنید. workflow با نام `build-app` خودش اجرا می‌شود (۵ تا ۱۰ دقیقه). اگر اجرا نشد، آن را انتخاب و Run workflow بزنید.
4. بعد از موفقیت، از بخش **Releases** ریپو فایل `CIBuilder.apk` را روی گوشی دانلود و نصب کنید. (اجازهٔ نصب از منبع ناشناس را بدهید.)
5. اگر `build-app` خطا داد، متن خطای مرحلهٔ build را برای من بفرستید.

## توکن
Settings → Developer settings → Fine-grained tokens: توکنی فقط برای همین ریپو با دسترسی‌های Contents و Actions (Read and write) بسازید.

## استفاده
1. توکن و `owner/repo` را وارد و ذخیره کنید.
2. نام برنامه، فایل زیپ و نوع (APK یا EXE) را انتخاب و «کامپایل» بزنید.
3. کامپایل در پس‌زمینه ادامه پیدا می‌کند (حتی اگر اپ را ببندید) و در پایان با صدای آلارم و ویبره خبر می‌دهد.
4. خروجی در Downloads ذخیره می‌شود؛ در صورت خطا لاگ در اپ نمایش داده می‌شود.
5. بعد از پایان، زیپ، release، artifact و run از گیت‌هاب پاک می‌شوند.

نکته: برای اینکه سیستم اپ را وسط کار نبندد، در تنظیمات گوشی بهینه‌سازی باتری اپ را روی «بدون محدودیت» بگذارید.

## Secretها
- در صفحهٔ «Secretها» به ازای هر نام برنامه مقدار اضافه کنید؛ رمزنگاری‌شده روی گوشی می‌ماند.
- موقع کامپایل داخل زیپ (فایل موقت `.build-secrets.env`) به workflow می‌رسند و به‌صورت متغیر محیطی در دسترس‌اند (در لاگ ماسک می‌شوند).
- امضای APK: `KEYSTORE_BASE64` (با «افزودن فایل»)، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`. بدون این‌ها نسخهٔ debug ساخته می‌شود.
- «دانلود بک‌آپ» و «بازیابی بک‌آپ»: secretها به/از فایل JSON (رمزنگاری‌نشده).

## انواع پروژه
- **APK:** پروژهٔ Gradle
- **EXE (ویندوز):** `.csproj`، `.sln`، `CMakeLists.txt` یا `build.bat`

## محدودیت‌ها
- اگر پروسهٔ اپ به‌زور کشته شود، پاک‌سازی ناقص می‌ماند؛ artifactها بعد از ۱ روز خودکار پاک می‌شوند ولی release موقت را دستی حذف کنید.
- ریپوی عمومی: لاگ و artifact تا لحظهٔ پاک‌سازی برای دیگران قابل دیدن است.
- .NET Framework قدیمی با `dotnet build` ساخته نمی‌شود.
